# TikTok LIVE Games

Набор игр для TikTok LIVE. Один Docker-контейнер слушает чат эфира и показывает
игру на странице, которую ты захватываешь в TikTok LIVE Studio (или открываешь на телефоне).

| Игра | Зрители пишут в чат | Суть |
|---|---|---|
| **Team Battle** | `R` / `Y` | перетягивание: красные против жёлтых, новые зрители усиливают команду последнего комментатора |
| **Guess the Word** | любое английское слово | найди секретное слово; каждая догадка получает ранг семантической близости |

Игра выбирается в меню (`/`). Выбор хранится на сервере: если выбрать игру с телефона,
окно в LIVE Studio переключится само.

## Быстрый старт (Docker)

Нужен только Docker Desktop.

1. Скопируй `.env.example` в `.env` и впиши свой ник: `TIKTOK_USERNAME=tvoy_nick`.
2. В папке проекта:
   ```
   docker compose up -d --build
   ```
   Первая сборка ~5–10 минут: в отдельной стадии скачиваются torch и модель и считаются
   эмбеддинги словаря. Следующие сборки берут это из кэша. Итоговый образ ~270 МБ (без torch).
3. Открой `http://localhost:8765` и выбери игру.
   С телефона в той же Wi-Fi: `http://<IP-компьютера>:8765` (`ipconfig` → «IPv4-адрес»).
4. Логи: `docker compose logs -f`. Остановить: `docker compose down`.

Игра слушает чат, **только пока идёт твой LIVE**; если эфира нет — пробует каждые 15 секунд.

**Без стрима (симуляция):** `SIMULATE=1` в `.env` → `docker compose up -d` — играют фейковые зрители.
Без Docker: `pip install -r requirements.txt`, собрать словарь (см. ниже), `python -m app --simulate`.

## Адреса

| URL | Что |
|---|---|
| `/` | меню выбора игры |
| `/battle/`, `/guess/` | экраны игр (9:16) — это захватывать в LIVE Studio |
| `/debug/` | кнопки для теста: раунд, победитель, подсказка, подарок, все анимации |
| `/health` | статус: активная игра, подключение к TikTok |
| `/state.json` | состояние активной игры (отладка) |
| `WS /ws` | живые обновления для экранов (если WebSocket недоступен — опрос раз в 0,5 с) |
| `POST /reset` | обнулить активную игру |

Параметры страницы: `?sound=0` — без звука, `?voice=luna` — выбрать голос, `?poll=1` — без WebSocket.

## TikTok LIVE Studio

1. Открой игру отдельным окном 9:16:
   ```
   start msedge --app=http://localhost:8765 --window-size=540,960
   ```
2. LIVE Studio → «Добавить источник» → **Захват окна** → окно игры. Окно не сворачивай.
3. Звук: захват окна передаёт только картинку — нужен источник «Звук рабочего стола».
   Один раз кликни «Click to enable sound» на странице. Голос лучше всего в Edge.
4. Если звук слышен дважды — где-то открыта вторая страница игры (выключи 🔇) или
   включено прослушивание эфира.

Кнопки внизу экрана: ☰ меню, ? правила (Guess the Word), 🗣 сменить голос, 🔊/🔇 звук.

## Guess the Word

- Секретное слово — частое английское существительное; угадывать можно ~30 000 слов
  (формы вроде `oceans` приводятся к `ocean`). Ранг = место слова по близости к секрету
  (#1 — само слово). Температуры: PERFECT, BURNING (#2–10), VERY HOT, HOT, WARM, COLD, FREEZING.
- Раунд: отсчёт 3-2-1-GO → игра (NORMAL 3,5 мин, каждый 4-й — SPEED 75 с; настраивается) → победитель →
  пауза ~2 мин: первые 25 с итоги (пьедестал, лучшие догадки, лидеры стрима), дальше промо-экран
  (призыв подписаться и вступить в игру, правила, таймер до старта) → новый раунд.
- Первый, кто прислал точное слово, побеждает; по таймауту — лучший ранг (при равенстве — кто раньше).
- Антиспам: одна догадка в 3 с на зрителя, повтор своего слова игнорируется.
- События с анимацией и звуком: NEW LEADER, COMEBACK, MASSIVE JUMP, BIG IMPROVEMENT,
  SO CLOSE (#2), TOP 3/10/50/100, WIN STREAK, HINT, TIME'S UP, подарки, подписки.
- Подсказки: подарок из `GIFT_HINT_NAMES` (по умолчанию Rose) или автоматически, если к
  середине раунда никто не ближе #300. Типы: близкое слово, категория, первая буква/длина,
  «секрет в TOP N от слова X».
- Сложность подстраивается: два быстрых раунда подряд → слова сложнее; никто не подобрался → проще.
- Слова не повторяются в рамках одного эфира. Новый эфир (новый room id) обнуляет лидерборд стрима.

### Словарь и эмбеддинги

Собираются один раз в стадии `assets` Dockerfile скриптом `tools/build_assets.py`:

1. **Источник слов** — `wordfreq` (топ-120 000 английских слов; код MIT, данные CC BY-SA 4.0).
2. **Препроцессинг** — только `a–z`, 3–15 букв; без мата (`better_profanity`, MIT);
   в словарь угадываемых попадают только базовые формы по WordNet 3.0, остальные формы
   становятся алиасами (`women → woman`). Берутся 30 000 самых частых.
3. **Секретные слова** — существительное должно быть основной частью речи (частоты SemCor
   в WordNet), единственное число, не имя собственное, не аббревиатура, не герундий, не больше
   12 значений; плюс стоп-лист тем, неуместных на эфире. Три пула по частоте (easy/medium/hard),
   всего ~3 100 слов → `assets/english_nouns.txt`.
4. **Эмбеддинги** — `sentence-transformers/all-MiniLM-L6-v2` (Apache 2.0), нормализованные,
   float16 → `assets/embeddings.npy`. В рантайме модель не нужна: ранжирование — одно
   умножение матрицы в numpy (миллисекунды).
5. **Проверка** при сборке: для `ocean` слова sea/water/wave ближе, чем computer/banana.

## Данные (папка `data/`, переживают перезапуски)

| Файл | Что |
|---|---|
| `session.json` | активная игра, номер текущего эфира |
| `battle.json` | счёт перетяжки |
| `guess/state.json` | текущий раунд (секрет, догадки, игроки) |
| `guess/players.json` | лидерборд стрима: победы, пьедесталы, серии, лучший ранг |
| `guess/rounds.json` | история раундов |
| `guess/used_words.json` | уже загаданные в этом эфире слова |

Новый эфир обнуляет игры автоматически. Вручную: `curl -X POST localhost:8765/reset`
(обнуляет активную игру) или кнопка на `/debug/`.

## Настройки

Все параметры — в `.env` (см. `.env.example` с комментариями): длительность раундов,
антиспам, границы температур, подарки для подсказок и нового раунда, цель стрима и т.д.
Цвета — CSS-переменные в `app/web/common/neon.css`.

## Структура (как добавить игру)

```
app/
  main.py            запуск: python -m app [--simulate]
  config.py          все настройки из env
  hub.py             активная игра, тики, сохранение, рассылка по WebSocket
  server.py          HTTP/WS API (FastAPI)
  storage.py         JSON-хранилище (можно заменить на SQLite)
  tiktok/client.py   подключение к TikTok: без игровой логики
  games/
    base.py          интерфейс игры: on_comment/on_join/on_gift/on_follow, tick, snapshot
    battle/          Team Battle
    guess/           Guess the Word: game.py (машина состояний), semantic.py, hints.py, players.py
  web/
    index.html       меню
    common/          live.js (WS + опрос), audio.js (звук, голос, кнопки), neon.css, base.css
    battle/ guess/   экраны игр
    debug/           отладочные кнопки
tools/build_assets.py  словарь + эмбеддинги
tests/                 python -m unittest (в контейнере)
```

Новая игра: папка `app/games/<name>/` с подклассом `BaseGame`, страница
`app/web/<name>/index.html` (подключи `common/live.js` и `common/audio.js`), строка в
`app/games/__init__.py` — и она появится в меню.

## Тесты

```
docker run --rm -v "%cd%/tests:/app/tests" election-game python -m unittest discover -s tests -v
```

## Честные оговорки

- Подключение к чату — через неофициальную библиотеку TikTokLive; если TikTok поменяет
  протокол, пересобери образ: `docker compose build --no-cache`.
- TikTok присылает не все события входа зрителей и иногда блокирует поиск эфира по
  странице профиля (игра использует API-поиск).
- Комментарии доходят с задержкой в 1–3 секунды.
- Телефон и компьютер должны быть в одной Wi-Fi сети.
