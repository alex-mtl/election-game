# TikTok LIVE «Перетяжка» — красные vs жёлтые

Простейшая игра для стрима. Зрители пишут в чат **К** (красные) или **Ж** (жёлтые) —
каждый такой комментарий = 1 тап. Красный тап расширяет красную половину на 1%,
жёлтый — жёлтую. Кто первым займёт весь экран — побеждает.
MVP раунда — игрок, сделавший больше всех тапов за победивший цвет.
Через 15 секунд после победы — новый раунд.

## Как запустить (Docker)

Нужен только Docker Desktop — Python ставить не надо.

1. Скопируй `.env.example` в `.env` и впиши свой TikTok-ник:
   ```
   TIKTOK_USERNAME=tvoy_nick
   SIMULATE=0
   ```
2. В папке проекта:
   ```
   docker compose up -d --build
   ```
3. Открой `http://localhost:8765` — игра на ПК.
   С телефона (в той же Wi-Fi): `http://<IP-компьютера>:8765`, IP — через `ipconfig`,
   строка «IPv4-адрес». Если Windows спросит про брандмауэр — разреши для частных сетей.
4. Скрипт слушает комментарии **только пока идёт твой LIVE**. Логи:
   ```
   docker compose logs -f
   ```
5. Остановить: `docker compose down`.

Проверка без стрима: в `.env` поставь `SIMULATE=1` (или оставь ник `CHANGE_ME`)
и перезапусти `docker compose up -d` — тапают фейковые зрители.

После правки `.env` достаточно `docker compose up -d`; после правки кода или
`game.html` — `docker compose up -d --build`.

## Звук и голос

Звуковые эффекты (тап, вход зрителя, победа, новый раунд) и голосовые фразы
генерируются браузером. После открытия страницы один раз кликни
«Click to enable sound». Кнопка 🔊/🔇 в правом нижнем углу — вкл/выкл,
`?sound=0` в адресе — открыть без звука. В LIVE Studio звук идёт через захват
звука рабочего стола (захват окна звук не передаёт).

## Счёт сохраняется

Счёт пишется в `data/state.json` (раз в секунду и при остановке) и
восстанавливается после перезапуска контейнера, обновления кода или перезагрузки ПК.
Начать с нуля: `docker compose down`, удалить `data/state.json`, `docker compose up -d`.

## Настройки (в `.env`)

- `HOST_PORT=8765` — порт на ПК
- `STEP_PCT=1.0` — на сколько % растёт половина за тап
- `TAP_COOLDOWN_SEC=1.0` — антиспам: пауза между засчитанными тапами одного игрока
- `WIN_PAUSE_SEC=15` — сколько висит табличка победы
- Ключевые слова команд — `RED_KEYS` / `YELLOW_KEYS` в `tug_of_war.py`

Без Docker тоже работает: `pip install -r requirements.txt`, `python tug_of_war.py`
(переменные окружения те же, `--simulate` — фейковые зрители).

## Как зрители играют

Пишут в чат одну букву: **К** — красные, **Ж** — жёлтые (принимаются также
red/yellow, «красный», «жёлтый» и т.п.). Тапать можно много раз, но не чаще
одного засчитанного тапа в секунду с человека.

## Честные оговорки

- Подключение к комментариям — через неофициальную библиотеку TikTokLive:
  если TikTok поменяет протокол, понадобится пересобрать образ (`docker compose build --no-cache`) — подтянется свежая версия.
- Комментарии доходят с задержкой в пару секунд — это нормально.
- Телефон и компьютер должны быть в одной Wi-Fi сети, иначе телефон не откроет страницу.
